# 🌙 Night Clock

Умные часы на ESP8266 с 4-разрядным дисплеем TM1637 и веб-панелью управления.

## 📖 О проекте

**Night Clock** — это компактное устройство, которое показывает точное время (синхронизация по NTP) и автоматически регулирует яркость дисплея в зависимости от времени суток, восхода/заката или уровня освещённости. Управление настройками осуществляется через встроенный веб-интерфейс, доступный по IP-адресу устройства в локальной сети.

### ✨ Возможности

- 🕐 **Точное время** — синхронизация с несколькими NTP-серверами, поддержка часовых поясов (POSIX TZ).
- 💡 **Адаптивная яркость** — три режима на каждый день недели:
  - ⏰ **Время** — фиксированный интервал «ночь/день».
  - ☀️ **Солнце** — по восходу и закату с ручной коррекцией.
  - 🌅 **Гибрид** — комбинация времени и солнца с жёстким лимитом.
- 🌗 **Плавное изменение яркости** — от 0 до 60 секунд.
- 📶 **Wi-Fi** — несколько сохранённых сетей, автоматический перебор, AP-режим для настройки.
- 🎉 **Праздничные дни** — отдельное расписание для праздников.
- 🔘 **Кнопка «Сон»** — физическая кнопка для мгновенного отключения дисплея.
- 🌞 **Фоторезистор** — опциональная адаптация яркости к освещённости в комнате.
- 🌐 **Веб-панель** — современный интерфейс с вкладками, статусом и превью дисплея.

## 🧩 Аппаратные компоненты

| Компонент | Назначение |
|---|---|
| **ESP8266-12F** | Микроконтроллер с Wi-Fi |
| **TM1637 4-DigiLED** | 4-разрядный семисегментный дисплей |
| **Кнопка** | Режим «Сон» (подключена к D7) |
| **Фоторезистор** | Адаптивная яркость (подключён к A0) |
| **Резистор** | Верхнее плечо делителя для фоторезистора |

### 🔌 Схема подключения

| Сигнал | ESP8266 | Примечание |
|---|---|---|
| CLK | D6 (GPIO12) | Тактирование TM1637 |
| DIO | D5 (GPIO14) | Данные TM1637 |
| BTN | D7 (GPIO13) | Кнопка «Сон» (INPUT_PULLUP) |
| LDR | A0 (ADC) | Фоторезистор (опционально) |

### 📚 Описание модулей

- **`config_manager`** — хранит все настройки в `config.json` на LittleFS. Загружает, сохраняет, предоставляет доступ к расписанию и праздникам.
- **`display_manager`** — управляет TM1637: неблокирующее плавное изменение яркости, вывод времени, анимации «PLAY» и «----».
- **`ntp_manager`** — запускает SNTP, применяет POSIX-таймзону через `configTime()`, отдаёт локальное время.
- **`wifi_manager`** — подключается к сохранённым сетям по очереди, переходит в AP-режим при неудаче, поддерживает отложенный перезапуск.
- **`brightness_engine`** — вычисляет целевую яркость с учётом дня недели, режима (время/солнце/гибрид), праздников и освещённости.
- **`web_server`** — асинхронный HTTP-сервер с REST API для чтения/записи конфигурации и сканирования Wi-Fi.
- **`main`** — связывает все модули: конечный автомат `BOOT → WIFI_WAIT → NTP_WAIT → RUN`, обработка кнопки, обновление времени.

## 🛠️ Сборка и прошивка

### Требования

- [PlatformIO IDE](https://platformio.org/) (VS Code + расширение PlatformIO).
- Драйвер CH340 (для плат с USB-чипом CH340).

### Шаги для нового устройства

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/AdmiralMK/NightClock.git
   cd NightClock

Установите зависимости:

bash
pio pkg install
Заливайте файловую систему (LittleFS):

bash
pio run -t uploadfs
Если config.json отсутствует, он будет создан автоматически при первом запуске с настройками по умолчанию.

Прошивайте микроконтроллер:

bash
pio run -t upload
Откройте Serial-монитор:

bash
pio device monitor
Первое подключение:

Подключитесь к Wi-Fi сети AdmiralNET-K (пароль 123456987 по умолчанию — измените в веб-панели).

Найдите IP-адрес в Serial-мониторе или в списке клиентов роутера.

Откройте http://<IP-адрес>/ в браузере.

💡 Совет: Если устройство не подключается к Wi-Fi, через 1 минуту оно создаст точку доступа NightClock-Setup. Подключитесь к ней и откройте http://192.168.4.1/ для настройки.

## 📌 Важные замечания

**Пароли:** Убедитесь, что в `config_manager.cpp` и других файлах не осталось реальных паролей от Wi-Fi. Скрипт не проверяет содержимое, поэтому перед публикацией стоит вручную просмотреть `config.json` (если он есть в `data/`) и удалить его из индекса Git.
**`.gitignore`:** Рекомендую добавить в проект `.gitignore` со строками:
- .pio/
- .vscode/
- data/config.json
  
Это исключит служебные файлы и локальные настройки из репозитория.
- **Имя репозитория:** В скрипте используется `NightClock` (без пробела), так как GitHub не рекомендует пробелы в URL. Отображаемое имя можно задать в описании репозитория на GitHub.
